# Playwright Automation

> [!NOTE]
> This documentation and the associated scripts were auto-generated by **Antigravity**.

This directory contains scripts and instructions for using Playwright to automate browser interactions.

## Installation

To install Playwright and the required browsers in your Python environment:

```bash
# 1. Install the Playwright package
pip install playwright

# 2. Install the browser binaries (e.g., Chromium)
playwright install chromium
```

*Note: If you are using a virtual environment (recommended), ensure it is activated or use the full path to the python executable (e.g., `.venv/bin/python`).*

## Recording a New Script

You can use the Playwright Code Generator (`codegen`) to record your browser interactions and automatically generate code.

**Command:**
```bash
playwright codegen --browser chromium -o playwright/your_script_name.py
```

**Important:**
- Always use the `-o` flag followed by a filename (e.g., `playwright/my_script.py`) to **save the generated code**. If you omit this, the code will only be shown in the inspector window and will be lost when you close it.
